# Components in src/Game/Components.h that are DELIBERATELY not registered with
# ComponentRegistry (src/Game/ComponentRegistry.cpp). Every struct in Components.h whose name
# ends in "Component" or "Tag" must be either registered there or listed here with a reason —
# check_component_registration.py (run in CI and locally) fails otherwise. This is the
# structural half of the "ship components fully wired, or not visible" rule (top of ComponentRegistry.cpp):
# a new component can't be added without a conscious decision about how the editor surfaces it.
#
# Format: one "Name = reason" per line. Blank lines and #-comments ignored.

TransformComponent      = Identity. Every entity has one; the Inspector's Transform section is a bespoke widget (per-axis reset, gizmo-space interplay), not a generic field list.
NameComponent           = Identity. Edited via the Inspector name row, not an Add-Component section.
OrderComponent          = Serializer-internal stable ordering (see the comment on the struct). No user-facing control.
HierarchyComponent      = Parent/children graph. Surfaced by the Scene Hierarchy panel's drag-reparent, not an Inspector section.
FirstPersonControllerComponent = Temporary native runtime view resolved from project PlayerDefinition; never authored or serialized as a native component.
DetachedMeshComponent   = Editor-only, never serialized. Holds the mesh removed via "Mesh Renderer" so re-adding restores it.
PrefabInstanceComponent = #236 A2 prefab-instance stub. Its scene representation is a one-line stub written by a dedicated serializer path, not a generic component block.
LevelGeometryTag        = Structural: selects the Hierarchy section and the "boxes" vs "models" JSON array an entity round-trips through.
TagComponent            = Free-text classification with a project-defined vocabulary dropdown (ProjectSettings); rendered as an Inspector header field, not an Add-Component section.
LayerComponent          = Slot index with human names from LayerRegistry (project/layers.json); rendered as an Inspector header field.
InactiveTag             = Derived activeInHierarchy (#201): set by World::SyncActiveInHierarchy from DeactivatedTag on the entity or an ancestor. Never saved.
DeactivatedTag          = The "active" checkbox in the Inspector header / Hierarchy (Unity's activeSelf), saved as "active": false.
StaticTag               = The "Static" checkbox in the Inspector header.
HiddenInSceneTag        = Editor Scene-view "hidden" column in the Hierarchy (#236 B). No runtime effect.
SceneLockedTag          = Editor Scene-view "locked" column in the Hierarchy (#236 B). No runtime effect.
LodCulledTag            = Runtime-only (#163): set per view by World::ApplyLod on renderers of LOD levels the view isn't using. Never saved, no Inspector.
ViewModelTag            = Runtime-only: FirstPersonPresentation::Start sets it on the spawned arms + weapon so SceneRenderer draws them in the view-model sub-pass. Those entities only exist during Play; never saved, no Inspector.
PlayerBodyTag           = Runtime-only: FirstPersonBody::Start sets it on the player's body pieces (Stop removes it) so the camera's world pass skips what of them is within Near Hide of the eye. The entities are scene objects but the tag only exists during Play; never saved, no Inspector.
PoseSourceTag           = Runtime-only: FirstPersonBody::ArmsLateUpdate sets it on the first-person arms rig once the body's arms take its hands, so the rig keeps animating but is never drawn and casts no shadow. The entity only exists during Play; never saved, no Inspector.
OutfitHideTag           = Runtime-only: OutfitSystem::UpdateHiding sets it on outfit pieces whose skin clothing covers (a per-vertex bit buffer the vertex shader reads). Rebuilt from the outfit whenever its pieces change; never saved, no Inspector.
OutfitLayerTag          = Runtime-only: OutfitSystem::UpdateHiding sets it on outfit pieces worn under other layers (how much nearer the camera ModelVertex.glsl draws them). Rebuilt from the outfit whenever its pieces change; never saved, no Inspector.
OwnerViewOnlyTag        = Runtime-only (split poses): FirstPersonPresentation::PlaceWorldWeapon sets it on the first-person gun so only the player's own camera draws it (no other view, no shadow). The entity only exists during Play; never saved, no Inspector.
HiddenFromOwnerTag      = Runtime-only (split poses): set on the world copies of the gun and the body (FirstPersonBody::MakeTwins, PlaceWorldWeapon) so every view but the player's camera draws them, and they cast the shadows. They only exist during Play; never saved, no Inspector.

NpcSpawnComponent = Runtime-only cached view of project NpcDefinition; authored/serialized as C# scripts.

SquadSettingsComponent = Runtime-only cached view of project SquadDefinition; authored/serialized as C# scripts.

WeaponAudioComponent = Cached runtime projection of project C# WeaponAudioDefinition; not authored or serialized.
FoleyAudioComponent = Cached runtime projection of project C# FoleyDefinition; not authored or serialized.
FxHudSettingsComponent = Cached runtime projection of project C# EffectsDefinition; not authored or serialized.

ImpactAudioComponent = Cached runtime projection of project C# ImpactAudioDefinition; not authored or serialized.

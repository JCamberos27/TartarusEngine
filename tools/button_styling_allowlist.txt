EditorModuleAssetBrowser.cpp = A fully transparent (zero alpha at every state, including hover) click target with no visual button treatment at all - not ActionButton-shaped, since ActionButton always paints a hover wash.
EditorModuleHierarchy.cpp = Pre-existing ActionButton-shaped debt (a Create/Cancel-style button pair with a fixed hover/active fill), not yet migrated.
EditorModuleToolbar.cpp = The window min/max/close cluster's batched style push (one push/pop covers three buttons plus a nested close-specific red override - doesn't map onto ActionButton's per-call push/pop/tooltip-ID shape) plus several CARET_DOWN dropdown-caret icon buttons that ARE pre-existing ActionButton-shaped debt, not yet migrated.
GameViewPanel.cpp = The aspect-ratio control's HUD button, styled via EditorUIPrimitives::kHudPlateColor (the viewport-HUD legibility system, Defect #54) rather than the panel-chrome button system - a deliberate different token family, not debt.

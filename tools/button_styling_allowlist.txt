# Allow-list for tools/check_button_styling.py (Phase 1 item 7 / #160).
# One line per file: <filename> = <reason>. Coarse-grained (whole file, not per-line) — see the
# script's own docstring for why. This is a BASELINE snapshot of what manually pushed
# ImGuiCol_Button*/Hovered/Active at the time this check was added, not a blessing that every
# occurrence in a listed file is correct forever — most entries below are pre-existing debt this
# check exists to stop from growing, not a claim that they're all deliberate one-offs.
#
# Format: one "Name = reason" per line, matching tools/component_registration_allowlist.txt.
# Blank lines and #-comments ignored.

EditorLayer.cpp = Preferences > Shortcuts: (1) the keybinding pill (ImGui::Button + pushes) is a fixed-width 124px chip whose fill/hover colour encodes capture state (idle/capturing/conflict) - a state-coloured text field, not an icon ActionButton; (2) the Layers panel's colour-coded filter chip (fill colour varies per filter). The shortcut reset buttons were migrated to ActionButton.
EditorLayer_Inspector.cpp = (1) AxisButton: the transform X/Y/Z slim axis-coloured tabs (colour IS the information); (2) the asset/material/mesh slot pickers (texture, mesh, material slots: ~7 ImGui::Button calls) are full-width value fields showing the assigned asset name with a clear-x reserve, styled as fields (FrameBg pushes), not buttons - no primitive models a field-shaped button; (3) the panel-wide flat Button/Hovered/Active push in DrawInspectorBody so the remaining field-style buttons inherit the flat language. The texture channel-preview strip moved to Segmented.
EditorLayer_Toolbar.cpp = Only the Play button remains raw: green SuccessColor text + green hover/active washes (the single accent in an otherwise monochrome toolbar, Defect #54) - ActionButton has no custom-tint variant. The flat Button* push at the top of DrawPlayTransportButtons is the shared baseline for the transport row. Stop/Step/Fullscreen now use ActionButton.
EditorModuleAssetBrowser.cpp = The breadcrumb path segments: text links (secondary text, no body, a hover wash) laid out edge to edge between chevrons - not ActionButton-shaped, since ActionButton draws icons at a fixed square size.
EditorModuleConsole.cpp = The Info / Warning / Error level toggles: each is tinted in its own severity colour when shown (the colour IS the information, like the Inspector axis buttons), dim when hidden - not the gold 'on' state ActionButton draws.
EditorModuleToolbar.cpp = The window min/max/close cluster: three joined square title-bar buttons sharing one batched style push (zero spacing/rounding) with a nested Windows-red close hover override - does not map onto ActionButton's per-call push, tooltip-ID shape or accent hover. All three have tooltips.
GameViewPanel.cpp = The aspect-ratio dropdown button and the stats toggle: HUD-plate buttons styled via EditorUIPrimitives::kHudPlateColor (the viewport-HUD legibility system, Defect #54) rather than the panel-chrome button system - a deliberate different token family, not debt. Both have tooltips.
EditorLayer_Outfit.cpp = The Character Outfit editor's gender pills, slot tabs and colourway pills (accent fill when selected, frame fill otherwise, wrapped flow layout with a worn-dot overlay - Segmented is a single joined strip and cannot wrap) plus the 'Remove' button, a solid DangerColor-filled text button (DangerIconButton is flat/icon-only and SecondaryButton is neutral).
